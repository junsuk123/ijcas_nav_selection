# 순환형 R-GAT 간선 선택 · 항법 알고리즘 선택 — 구현 설계와 사전 등록

작성일: 2026-11-16. 학습 결과를 보기 전에 데이터·학습 목표·기준선·평가 규칙을 고정하기 위한 문서다.
이 문서의 규칙은 검증 데이터 결과를 본 뒤에도 바꾸지 않는다. 바꿀 경우 변경 이유와 시점을 아래 '변경 기록'에 남긴다.

## 1. 연구 정의

센서·환경·항법기 진단 정보의 시간적 변화를 노드별 기억에 누적한다. 온톨로지 제약 아래 필요한 정보 전달 간선을 선택해, 상태 추정 오차가 작은 항법 알고리즘 하나를 고른다.
학습 후 불필요한 후보 연결을 제거해 희소 관계 구조 E\*를 확정한다. 운용 중에는 E\* 안에서 활성 간선과 선택 결과만 갱신한다. 가중치는 운용 중 학습하지 않는다.

- 선택기는 후보 항법기(GNSS/INS, VIO, LIO, INS 전파)를 대체하지 않는다. 출력 하나를 고를 뿐이다.
- 후보 항법기는 선택과 무관하게 독립 실행된다. 선택 결과는 어떤 항법기의 내부 상태도 바꾸지 않는다.

## 2. 항법 온톨로지 계층과 구현의 대응

| 계층 | 요소 | 이 구현에서의 대응 | 학습 여부 |
|---|---|---|---|
| 의미론적 | Objects | 계산 노드 12개(환경·운동 4, 센서 품질 4, 항법 알고리즘 4), 상태 출력 노드(계산 없음), 임무 요구(전역 waypoint: 출력 age ≤ 0.3 s, 경보 2 m), 결함 사건(평가용 라벨만, 입력 아님) | 고정 |
| 의미론적 | Properties | 노드 특징: 가용성·신선도(age)·신뢰도·잡음·불확실성(공분산)·지연·초기화/정렬/reset 상태, 측정 능력별 4단계 사실 상태 | 고정(값은 관측) |
| 의미론적 | Links | 관계 유형 6개. `sensor>nav:def`는 온톨로지 `requiresEssential`/`usesAiding`에서 온 정의 관계(보호). 나머지는 계산용 후보 관계(degrades/supports, suitableFor, dependsOn, 교차검증) | 정의 관계 고정, 후보 관계 학습·프루닝 |
| 동역학적 | Functions | 순환형 R-GAT: 상황 평가(노드 기억), 간선 활성도, 관계 집계, 적합성 점수 | 학습 |
| 동역학적 | Policies | 적격성: 출력 age ≤ 0.3 s, VIO/LIO 인과 정렬 확보, 마지막 외부 보정 이후 시간 한계, INS 추측항법 10 s 한계. 전환: 최소 유지·복구 확인·margin, 적격 상실 시 즉시 제외 | 고정(전환 margin·유지 시간만 검증 세트에서 고정) |
| 동역학적 | Actions | 1차 구현은 출력 전환만 한다(정상/제한적/유효한 항법 없음). 항법기 활성화·중지·재초기화는 범위 밖이다. | — |

정의 관계 7개(IMU→4개 항법기, 카메라→VIO, LiDAR→LIO, GNSS→GNSS/INS)는 학습으로 지우지 않는다. 지우면 계산량이 줄어드는 것이 아니라 알고리즘에 대해 거짓을 말하게 되기 때문이다.
`tests/test_rgat.py`가 이 집합이 `ijcas/knowledge/ijcas_nav.ttl`과 같은지 확인한다.

### 3.1a S04(LiDAR 열화) 수준 재설정 (2026-11-16, 사용자 결정 'S04만 강화')

- **배경:** GLIM 기준으로 정한 수준(복도 장면만 / 점 dropout 0.9 / 거리 제한 4 m)에서 FAST-LIO2는 오차 0.2 m 이하로 버텼다. 이대로면 S04에서 'LIO 열화 시 전환'을 평가할 수 없다.

## 5. 모델 (`ijcas/rgat/model.py`)

한 시점 = 기억 갱신 → 간선 활성도 → 활성 간선 집계 → 기억 저장 → 선택 점수.

- 기억: 노드 종류별 공유 GRU(가중치 공유, 상태는 노드별). 입력 = [정규화 y, m, log Δt].
- 간선 점수: ℓ_e = (U_r u_j)ᵀ(V_r u_i)/√d_g + b_r, d_g = 16.
  - 학습: Hard Concrete(β = 2/3, γ = −0.1, ζ = 1.1).
  - 운용: p_e = P(z_e ≠ 0)에 히스테리시스(켜짐 ≥ 0.6, 꺼짐 ≤ 0.4)를 적용한 이진 z.
- 집계: 2층.
  - R-GAT: 관계별 W_r, 2 head(합계 32차원), z 가중 softmax.
  - R-GCN: 같은 게이트, 관계별 정규화 평균.
  - 자기 연결은 항상 켜져 있다.
- 운용 모드(차량 1대)에서는 활성 간선만 모아 계산하고, 영구 제거된 간선은 인덱스에서 빠진다.
- 선택 점수: 항법 노드 최종 특징 → 공유 MLP + 후보별 편향 → 적격 후보에 대한 softmax π.
- 크기: d = 32, 파라미터 65,035개.
- 비그래프 GRU 기준선은 은닉 72로 파라미터 65,020개를 맞췄다.

## 6. 학습 목표 (`ijcas/rgat/learn.py`)

- 후보 비용: c_k = ρ(|Δp|/1 m) + 0.5 ρ(|Δv|/0.5 m/s) + 0.5 ρ(Δθ/5°).
  - ρ(x) = x² (x ≤ 3), 3(2x − 3) (x > 3).
  - Δθ는 회전각 오차, 참값은 학습 라벨에만 쓴다.
- 손실: L = L_nav + λ_E L_edge + λ_S L_switch.
  - L_nav = Σ_k π_k (c_k − min_j c_j)를 적격 후보가 있는 시점에 대해 평균한다.
  - L_edge = 게이트 간선의 평균 P(z ≠ 0).
  - L_switch = ½‖π_t − π_{t−1}‖₁. 적격 집합이 바뀐 시점에는 적용하지 않는다.
- 보조항(2026-11-17 추가): L_CE = KL(q ‖ π), q_k ∝ exp(−(c_k − min_j c_j)/τ)(적격 후보), τ = 1, 가중치 1.
  - 기대 비용 항의 기울기 π_k(c_k − c̄)는 π가 한 후보로 포화되면 사라진다. 1차 학습에서 gru_flat 3/3, rgcn_dyn 1/3이
    적격 집합만으로 정해지는 고정 우선순위(LIO 미사용)에 정체했다. 보조항의 기울기는 π − q라 포화에서도 남는다.
  - 모든 학습 변형에 같은 값으로 적용하고, 값은 결과를 보기 전에 정했다(조정하지 않음).
- 혼합 위치 오차 ‖Σπp̂ − p\*‖는 쓰지 않는다. 반대 방향 오차가 상쇄되기 때문이다.
- 항법기 내부로는 역전파하지 않는다.
- 최적화: Adam 2e-3, 기울기 노름 1, 10 s 단위 TBPTT(기억은 끊지 않고 이어감), 학습 실행 전체를 한 배치로 둔다.
- 일정:
  - A: 넓은 후보 그래프, soft 게이트 40 에폭. λ_E는 처음 30 %는 0, 이후 0.1까지 선형 증가.
  - 구조 프루닝.
  - C1: E\*에서 soft 10 에폭.
  - C2: 이진 게이트(히스테리시스, straight-through) 10 에폭, 학습률 절반.
  - λ_S = 0.1.

## 7. 구조 프루닝과 동결 (`ijcas/rgat/experiment.py`)

1. **후보 선정:** val에서 운용 모드 게이트의 체제별(정상·단일 열화·복합 열화·복구) 활성률을 구한다. 모든 체제에서 최대 활성률이 0.05 미만인 간선만 제거 후보다. 평균 활성률만으로는 지우지 않는다.
2. **제거 판정:** 활성률이 낮은 순으로 하나씩 실제로 제거하고 val을 재평가한다. 다음 조건을 모두 만족할 때만 제거를 유지한다(제거 전 모델 기준).
   - 모든 체제의 위치 RMSE ≤ 기준 × 1.02 + 0.02 m
   - 모든 체제의 가용성 ≥ 기준 − 0.005
3. **확정:** 남은 연결 E\*에서 C1·C2로 미세조정한다. test를 보기 전에 E\*, 선택 규칙, 정규화, 가중치를 `results/rgat/FROZEN.json`(해시 포함)으로 동결한다.
4. **전환 규칙 고정:** margin {0, 0.05, 0.1, 0.2, 0.3} × 최소 유지 {0.5, 1, 2} s, 복구 확인 1 s. val 위치 RMSE 최소값의 2 % 이내 설정 중 전환이 가장 적은 것을 고르고, 같으면 유지 시간이 긴 것을 고른다. 모든 학습 변형에 같은 절차를 쓴다.

## 10. 사용자 초안 대비 구현상 결정 (이유)

1. **입력 변환을 노드별로 둔다.** 같은 종류 노드라도 제공 진단이 달라, 공유 선형층에 패딩하면 한 가중치가 여러 의미를 갖게 된다. GRU·게이트·집계·점수 가중치는 초안대로 공유한다.
2. **기억 저장을 h = tanh(v^(L))로 둔다.** 잔차 집계를 그대로 다음 은닉 상태로 쓰면 3,600 시점 동안 크기가 커질 수 있다.
3. **비용을 3σ 밖에서 선형(Huber)으로 둔다.** (2026-11-17 로그 꼬리를 시험했으나 정체가 그대로여서 Huber를 유지) 순수 제곱이면 수백 m 발산 몇 시점이 기울기를 독점한다. 단조성은 유지되므로 최선 후보의 순서는 같다. 개발 데이터에서 상한(cap)을 쓴 첫 시도는 큰 오차의 순서를 지워 폐기했다.
4. **적격성에 '마지막 외부 보정 이후 시간'을 넣는다.** 온톨로지 문서의 정책이다. 넣지 않으면 모든 보정을 잃고 표류하는 PX4 출력이 계속 적격이 되어, RMSE가 출력을 포기하는 선택기에 유리하게 왜곡됐다(개발 데이터에서 확인).
5. **INS 전파 후보의 고정점은 선택과 무관한 규칙(GNSS 위치 Usable 동안 PX4 상태)으로 둔다.** 마지막 선택 상태에 고정점을 잡으면 후보가 선택에 의존하게 된다.
6. **학습 선택기는 20 Hz, 규칙 기반 비교기는 동결된 10 Hz로 각자 평가한다.** RMSE는 시간 평균이다.

## 12. 충분성 판정과 검색 기반 선택(CR) (2026-11-17, 재학습 결과를 보기 전에 고정)

사용자 지시: "현재 방법이 충분하지 않으면, 제안된 검색 기반 방향을 참고하라."

### 12.1 '온라인 R-GAT이 충분한가' 판정 (val, `rgat_dyn` 3시드 평균)

1. 정확도: 위치 RMSE가 Ontology-K와 H-FSM보다 낮고, 가용성이 두 규칙 선택기 중 높은 값 − 0.005 이상.
2. 단일 항법기 대비: 가용성이 `rgat_dyn` − 0.005 이상인 F-\*가 있으면 그보다 위치 RMSE가 낮다.
3. 지연: CPU 1스레드, 차량 1대, 운용 모드에서 선택기 1 tick p99 ≤ 5 ms(20 Hz 주기 50 ms의 10 %).

- 모두 충족: 온라인 R-GAT을 주 방법으로 둔다. CR은 운용 경량화 대안으로 같은 동결·시험 절차에서 비교한다.
- 하나라도 미충족: R-GAT은 오프라인 관계 선별·검증 도구로만 쓰고, CR을 주 방법으로 전환한다.
- 어느 쪽이든 CR은 같은 동결 해시와 1회 시험 평가에 포함한다(사용자 제안의 핵심 비교 ①이 판정 근거이므로).

### 12.2 CR 구조 (`ijcas/rgat/retrieval.py`)

운용 중 그래프 신경망을 실행하지 않는다.

- **상황 특징 s_t = Φ(y≤t; E\*)** (신경망 아님): R-GAT과 같은 노드 입력(정규화 값, 결측 마스크, log age) + 값 채널의 이력 요약
  (EMA τ = 2 s, 10 s, 10 s 감쇠 최대값 유지). 시점당 O(D).
- **후보별 사례 공간:** 후보 k의 벡터는 N_k와 E\*에서 N_k로 직접 들어오는 관계의 노드 특징만 쓴다(1-hop).
  관계 축소가 검색 벡터 차원을 줄이는지 이 정의로 검증한다.
- **질의:** q_t^k = P_k s_t^k(고정 선형, d = 16). 대표 사례 M = 256개/후보, 저장 값 = 그 사례에 가까운 학습 시점들의
  실제 후보 비용 가중평균(측정 성능, 자유 파라미터 아님)과 지지량.
- **비용 추정:** 가장 가까운 16개 사례의 RBF 가중평균 ĉ_k → π = softmax(−ĉ)(적격 후보만) → 다른 변형과 같은 전환 규칙.
- **선택 보류:** 적격 후보 중 하나라도 가장 가까운 사례까지 거리가 학습 시점 99 백분위를 넘으면, 그 시점에는
  학습 기반 전환을 하지 않는다(정책 전환은 그대로). 보류 비율을 보고한다.
- **학습:** P_k와 대표 사례를 PCA·k-means로 초기화한 뒤, R-GAT과 같은 손실(기대 비용 + L_CE)로 30 에폭 학습한다.
  매 에폭 저장 비용을 경험값으로 다시 계산한다. 학습·검증 분할, 정규화, 전환 규칙 조정 절차는 R-GAT과 같다.

| 변형 | 특징 | 사례 공간 | 투영·사례 | R-GAT 정보 |
|---|---|---|---|---|
| `cr_plain` | 수치 특징만(온톨로지 상태 사실 제외) | 전역 1개 (d = 32, M = 1024) | PCA + k-means(비지도) | 없음 |
| `cr_e0` | 전체 노드 특징 | 후보별, 축소 전 E0(모든 노드) | 지도 학습 | 없음 |
| `cr_gstar` | 같음 | 후보별, `rgat_dyn` 같은 시드의 E\* | 지도 학습 | 관계 축소 결과 |
| `cr_gstar_kd` | 같음 | 같음 | 지도 학습 + KL(π_R-GAT ‖ π) 0.5 | 축소 + 선택 증류 |

- 비교: ① `rgat_dyn` vs `cr_gstar_kd`(그래프 연산 제거의 정확도 손실과 지연 감소),
  ② `cr_e0` vs `cr_gstar`(관계 축소가 정확도·차원에 주는 영향), ③ `cr_plain` vs `cr_e0`/`cr_gstar_kd`(온톨로지·R-GAT 정보의 이점).
- 지연: 특징 생성 + 투영 + 검색 + 조건 확인을 따로 재고, R-GAT 1 tick과 같은 조건(CPU 1스레드, B = 1)에서 비교한다.
  메모리(저장 실수 개수), 전환 수, 보류 비율도 보고한다.
- 시험 세트의 참값·최적 후보 정보는 사례에 넣지 않는다(사례 = 학습 분할 seeds 1–7).

    - 시각 오프셋: 검출은 된다(0.03 s, 정상 최대 0.005 s). 하지만 결함 구간 후보 오차가 1 m 이하였다.

- **바꾸지 않은 것:** 동결 지표(`thresholds_validated.yaml`), 규칙 비교기 설정, 특징 정의, 모델 구조, 손실, 학습 일정.
